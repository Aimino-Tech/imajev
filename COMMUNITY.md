# Community

This fork focuses on efficient, inspectable local typed-decision inference.

Useful contributions include reproducible hardware reports, scheduler improvements, memory reductions, correctness regressions, upstream-compatibility fixes, isolated kernel experiments, documentation and field reports.

Performance reports should include commit, hardware, OS, CUDA/Metal, torch/MLX, transformers, triton, precision, model/adapter, rotations, microbatch, suffix bucket, question prefill batch, command, p50, p95, peak memory and winner parity.

Negative results are welcome; they prevent repeated dead ends.

Near-term work: cross-hardware benchmarks, upstream compatibility, isolated modern FLA experiments, suffix-compute reductions, cache observability and regression fixtures from real field failures.
